# PostOnce（一稿多发）产品设计与技术方案

> v0.1 · 2026-10-01 · 状态：待评审

## 1. 产品定位

**一句话**：开源的 AI 跨平台内容二创 Agent——输入一次内容（粘贴文本 / 网页链接 / 视频 / 播客），自动产出适配小红书、公众号、知乎、微博、头条的发布级草稿（文案 + 标题候选 + 封面图 + 话题标签），人工确认后一键复制导出。

- **品牌**：PostOnce / 中文名「一稿多发」
- **Slogan**：Write once, publish everywhere. 写一次，发全网。
- **目标**：GitHub 开源（Apache 2.0）+ 免费在线 Demo，积累个人影响力，非商业化
- **生态位**（调研结论）：大厂平台黑盒 + 模型绑定，国际工具不接中国渠道，现有分发工具无 AI 深度改写——"开源透明 + 国产模型可插拔 + 本土平台原生适配"这个位置是空的

## 2. 设计原则（来自调研，不可妥协）

1. **1 分钟跑通核心体验**：粘贴链接 → 看到小红书图文成品，中间零配置
2. **人在回路**：每个中间结果可编辑、可单独重生成；不碰自动发布，只产出草稿
3. **模型可插拔**：OpenAI 兼容抽象层，默认国产免费/低价模型，支持 BYOK（用户自带 key）
4. **账单透明**：每次运行实时显示 token 消耗与预估成本；在线 Demo 按 IP 限流
5. **输出像平台原生内容**：不是"通用文案换个标题"，而是严格遵循各平台调性规格（见 §6）
6. **合规先行**：支持 AI 内容标识，强调"辅助真人创作"，不做账号托管（平台政策红线）

## 3. 用户与核心场景

**首要用户**：小红书/公众号创作者（含想起步的副业人群）。次要：技术博主、知识付费从业者。

核心用例：

1. 公众号长文 → 小红书爆款图文（3:4 封面 + emoji 分段正文 + 标签）
2. B 站/播客一期节目 → 公众号排版稿 + 小红书笔记 + 微博短文案（一期内容吃全网）
3. 一个想法/几行笔记 → 五平台草稿各一套，挑着改着发

## 4. 功能范围与分期

### Phase 1（MVP，核心链路）

- 输入：粘贴文本 + 网页链接抓取（公众号、知乎、普通网页）
- Agent 流水线：内容理解 → 平台化改写 → 标题候选 → 封面渲染 → 组装预览
- 输出：**小红书版**（标题 ≤20 字、emoji 正文、话题标签、3:4 封面图）+ **公众号版**（富文本排版，一键复制进后台）
- 封面：4-6 套精选模板，程序化渲染（标题+副标题+配色），秒出、免费、可控
- 模型：GLM-Flash（免费）/ DeepSeek（低价）默认 + BYOK；每次运行显示 token 用量
- 编辑：每个产出块可在线编辑、可单独重生成
- 无登录、无数据库：历史记录存浏览器 localStorage，支持导出

### Phase 2

- 视频/播客输入：B 站、YouTube、小宇宙链接 → 音频提取 → ASR 转文字稿 → 进流水线
- 输出扩展：知乎、微博、头条（各配适配规则）
- AI 生图封面（可选增强，接生图 API，用户自备 key）
- Docker 一键自托管（视频转写功能仅自托管开放，见 §8）

### Phase 3

- 选题雷达：输入账号定位 → 抓热点/竞品 → 输出选题日历 + 大纲（调研候选 2，作为内置模块）
- 自定义模板、模板市场、多语言（X/LinkedIn 英文输出）

## 5. Agent 流水线设计

```
[输入] 文本 / 链接 / 音视频
   │
   ▼
① 摄取层 Ingest ──→ 规范化文档（标题、正文、来源、字数）
   │                 ✋ 人可编辑
   ▼
② 理解层 Understand ──→ 结构化摘要（核心观点、要点清单、目标读者、情绪调性、金句）
   │                    ✋ 人可编辑/重生成
   ▼
③ 适配层 Adapt（按平台并行，流式输出）
   │   每平台 = 平台规格 prompt（风格/字数/结构/禁忌）+ 改写 + 自检
   │   ✋ 每个平台版本可单独编辑/重生成
   ▼
④ 标题候选 Titles ──→ 每平台 3-5 个候选（含点击率导向的多种风格）
   │
   ▼
⑤ 封面渲染 Cover ──→ 选模板 → 填入标题 → 渲染 3:4 PNG（可多套对比）
   │
   ▼
⑥ 组装导出 Export ──→ 预览台：逐平台预览 → 一键复制富文本/下载封面/导出 Markdown
```

- 编排：自研轻量 pipeline（步骤化 + 流式），不引入重型 Agent 框架——个人项目可控性优先
- 每个步骤的输出是结构化 JSON，前端分块渲染、分块可编辑
- 失败处理：单平台生成失败不影响其他平台；支持断点重跑

## 6. 平台适配规格（产品的核心 Know-how）

| 平台 | 标题 | 正文 | 配图/封面 | 其他 |
|---|---|---|---|---|
| 小红书 | ≤20 字，强情绪/数字/悬念，emoji 开头常见 | 短段落 + emoji 分隔，口语化，"姐妹/宝子"语气可选，800 字内 | 3:4 封面（文字大、对比强）+ 内图可选 | 5-10 个话题标签；主动 AI 标识选项 |
| 公众号 | 22 字内，悬念/观点型 | 富文本排版：小标题、引用块、加粗、分割线，3000 字内 | 封面 2.35:1 + 正文配图位 | 输出 HTML 一键复制进后台（样式内联） |
| 知乎 | 问题式/观点式 | 逻辑性强，小标题 + 列表，专业感 | 无强制 | 适合"回答体"改写 |
| 微博 | 前 20 字定生死 | 140 字内短文案 + 长文可选 | 1-3 图 | 话题 #xx# 格式 |
| 头条 | 信息量标题 | 段落清晰，资讯感 | 封面图 | 微头条/文章两规格 |

## 7. 技术架构

**栈**：Next.js 16（App Router）+ TypeScript + Tailwind + shadcn/ui，单体仓库，API Routes 做后端。

**关键选型**：

| 模块 | 选型 | 理由 |
|---|---|---|
| LLM 调用 | Vercel AI SDK（`ai` + OpenAI-compatible provider） | 流式 UI、多厂商抽象、自带 usage 统计，与 Next.js 原生契合 |
| 模型预设 | GLM-Flash（免费）、DeepSeek、通义、Kimi、OpenAI | 全部走 OpenAI 兼容接口；UI 一键切换 + BYOK |
| 链接抓取 | `@mozilla/readability` + cheerio | 公众号/知乎/网页正文提取，UA 伪装 |
| 封面渲染 | satori + @resvg/resvg-js → PNG | 纯 JS、Vercel serverless 可跑、模板即代码 |
| ASR（P2） | yt-dlp 提取音频 + Groq Whisper API（免费额度） | 零模型部署成本；仅自托管开放 |
| 限流 | 按 IP 计数（Upstash Redis / 自托管用内存版） | Demo 成本控制 |
| 存储 | MVP 无 DB（localStorage）；自托管可选 SQLite | 极简 |

**部署**：
- 在线 Demo：Vercel 免费 tier（无国内服务器/域名，先顶着；国内访问不稳时再迁，备选：国内云函数/轻量服务器 + 备案域名）
- 自托管：Docker Compose 一键（Phase 2）
- 视频转写属重任务（serverless 超时限制）→ 在线 Demo 只开放文本/链接输入，视频输入标注"自托管可用"，这也成为 GitHub star 的转化理由

**成本量级**：一次完整五平台改写约 5-8k tokens，用 GLM-Flash 免费 / DeepSeek 约 ¥0.01-0.02；Demo 按 IP 每日限 10 次，月成本可控在几十元内。

## 8. 合规设计

- 不做、不接任何平台自动发布 API；产出物为草稿，人工确认后自行发布
- 生成结果页提供「AI 辅助创作标识」一键添加（符合小红书/公众号 AI 标识政策）
- README 声明：抓取内容仅供用户本人二次创作，尊重原版权
- 前端默认展示「人工审核后再发布」提示

## 9. 仓库与 README 策略（star 增长要点，来自供给侧调研）

- README 顶部：10-20 秒演示 GIF + 一句话价值主张 + 在线 Demo 按钮（最高杠杆）
- 中英文双语 README
- 一键体验：`npx`/Docker/Vercel Deploy 按钮 + 在线 Demo
- 好公民配置：CONTRIBUTING、good-first-issue、CHANGELOG、Apache 2.0

## 10. 推广飞轮（产品即内容）

1. MVP 上线即发小红书：「我用自己做的开源 Agent，3 分钟把公众号长文变成小红书爆款笔记」——前后对比 15-60 秒视频
2. 公众号发深度复盘：设计思路、国产模型对比、成本账单全公开
3. Building in Public：开发日志、用户反馈、听劝式迭代
4. 每次自己发内容都用 PostOnce 生产——dogfooding 即素材
